# ブログの設計

kimuchan の記事と解説動画を置く公開サイト。しずかなインターネット(sizu.me)から 2026-10-18 に引っ越した。この文書は「何を・どこに・どう置くか」と、その理由を書く。実装の手順は README.md にある。

## 全体図

```text
書く場所                         このリポジトリ                          配信
 下書き(非公開リポジトリ)  ──▶  src/content/blog/*.md  ──┐
 解説動画(台本 → HTML)     ──▶  public/videos/*.html   ──┼─ pnpm build ─▶ GitHub Pages
                                 (video-*.md が 1 本ずつ記事にする)      (main への push で自動)
```

図が示しているのは、文章も動画も「1 本 = src/content/blog の 1 ファイル」で、ビルドと配信は push だけで済む、ということ。

## 決めたこと

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 置き場 | GitHub Pages + Astro、公開リポジトリ | 無料で、Markdown に生の HTML と script が通る。Node と pnpm が手元にある |
| 公開範囲 | すべて公開 | GitHub Free では非公開配信ができない。自分だけに見せる文章は書かない(下書きは非公開リポジトリに置く) |
| ページ構成 | トップ = 記事一覧、`/blog/<slug>/` = 記事 | トップと一覧を分ける意図がないので 1 つにした。`/blog` はトップへ転送 |
| 一覧 | 1 記事 1 行(日付 + 題名)、動画には「動画」ラベル | 題名を横に並べると比較する意味がないのに視線が往復する |
| 文章記事 | `.md`、BlogPost レイアウト | `.mdx` は script を Astro が処理するので、生で出したいときに `is:inline` が要る |
| 動画記事 | `video` と `duration` を frontmatter に持つ `.md`、VideoPost レイアウトで全幅表示 | 文章の途中に挟むと読みづらい。動画は動画で 1 本の記事にする |
| 動画の埋め込み | 同一オリジンの iframe。読み込み後に中身の高さへ合わせる | 動画 HTML は自前の CSS と JS を持つので、直接差し込むとブログ側と干渉する。iframe なら干渉せず、高さは JS で解決できる |
| 図 | Mermaid の fence をブラウザ側で描画(cdnjs の固定版) | ビルド時描画は Playwright が要る。読者側で描いても数十 KB で済む |
| 表 | Markdown の表をそのまま使う | BlogPost レイアウトに罫線の style を持つ |
| 画像 | 記事と同じディレクトリに置き、相対パスで参照 | Astro が最適化して `_astro/` に出す |
| ファビコン | GitHub のアバター | 他のサイト(self-introduction)と揃える |

## 書き方

ビジュアルシンカー向けに書く。文章より先に構造を置く。

1. 全体図を先に置く
   - 長い記事は本文の前に、全体が一目で分かる図か表か位置づけの 1 文を置く
2. 数値の比較は表にする
   - 実験の結果、Before/After の数字、条件の違いは表。箇条書きに数字を並べない
3. 関係と流れは Mermaid で描く
   - 依存・遷移・分岐・「こう見えるが実体はこう」は図。ラベルは `["..."]` でくくり、ノードは 7 個まで
   - 図の直前か直後に、図が示していることを 1 文書く
4. 図が効かないものに図を足さない
   - 数文で済む記事には何も足さない。並列の列挙は箇条書き
5. 文章は著者の言葉のまま
   - 図表を足すときも本文の文は変えない。言い換えは著者が行う

## 置かないもの

- 職場の内部情報(製品の内部構造、社内の固有名詞)
- 書籍の要約動画(著作物の派生なので、公開するかは著者が個別に決める)
- 下書き。`draft: true` でも公開リポジトリ上では読める

## 運用

- 記事を書く: `src/content/blog/<slug>.md` を置いて main に push する
- 動画を足す: `public/videos/<slug>.html` と `src/content/blog/video-<slug>.md` を置く
- 確認する: `pnpm build` が通ること、Mermaid を使った記事はブラウザで図が出ること
- 費用: GitHub Pages と Actions は公開リポジトリでは無料。上限はサイト 1 GB、転送 月 100 GB
