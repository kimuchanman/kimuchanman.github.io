2018 年 4 月から 2026 年 10 月までに実務で使った 25 の技術を、1 枚の地形図にしました。作ったのは、コードベースの習熟度を地図にする自作の skill(input-terrain-map)で、この記事ではリポジトリの代わりに自分のスキルを載せています。

## 図の読み方

- 山の高さは、その技術を実務で使った月数です。平方根で縮めているので、月数が 4 倍の山は 2 倍の高さになります
- 緑は今も使っている技術、茶色は過去に使った技術です。色が濃いほど、多くの職場・案件で使っています
- 線は職場(期間)ごとに使った技術を結んだものです。黒い線が今のチーム、茶色の線が過去の職場です
- 左右は、左がフロントエンド、右がインフラです。奥はテスト・CI・意思決定のような開発の周辺、手前はアプリケーションの本体です
- 「高さ」を「使った職場・案件数」に切り替えると、長さではなく広さで比べられます

## 高い山

| 技術 | 経験月数 | 職場・案件数 | 状態 |
| --- | --- | --- | --- |
| AWS | 116 | 7 | 現役 |
| Vue.js / Nuxt.js | 81 | 4 | 過去(最終 2022) |
| TypeScript | 79 | 4 | 現役 |
| E2E テスト | 68 | 3 | 現役 |
| GitHub Actions | 44 | 3 | 現役 |
| React / Next.js | 38 | 2 | 現役 |
| PHP(CakePHP・Laravel) | 38 | 2 | 過去(最終 2022) |

高い 7 つのうち、茶色は 2 番目の Vue.js と 7 番目の PHP です。どちらも最後に使ったのは 2022 年の BASE で、そこから右手前(バックエンド)の茶色い山と左奥の緑の山へ、主な仕事場が移ったことが地形の色の分かれ方に出ています。

## 数え方と限界

- 月数は[職務経歴書](https://kimuchanman.github.io/self-introduction/)に書いた在籍期間と、その期間の技術スタックから数えました。副業の期間が本業と重なる場合は両方に数えています
- AI エージェント基盤だけは、Claude Code の skill を最初にコミットした 2025 年 7 月から数えました
- 高さが表すのは使った期間の長さで、習熟度そのものではありません。同じ 25 か月でも、VRT 基盤のように自分で設計したものと、既存の仕組みを使っただけのものが同じ高さになります。習熟度に近づけるには、自己評価か、技術ごとのコミット数を高さに使う必要があります
